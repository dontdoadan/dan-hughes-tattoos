# Launch Checklist

## Offer and scope
- [ ] Confirm the ten project concepts and proposed 3 / 4 / 3 size mix.
- [ ] Confirm every selected project's coverage, placement and exclusions.
- [ ] Confirm the fixed price is viable for the scope and risk.
- [ ] Confirm the payment schedule and deposit collection process.
- [ ] Have a UK solicitor review the agreement, cancellation and deposit terms.

## Website and form
- [x] Campaign landing page created on a separate campaign branch.
- [x] Application form connected to the campaign Edge Function.
- [x] Campaign application database tables created.
- [x] Private image-upload bucket created.
- [x] Reference image upload validation added.
- [x] Privacy notice extended for campaign applications and image uploads.
- [ ] Test on iPhone Safari, Android Chrome and desktop.
- [ ] Test all required fields, optional marketing consent and contact-method validation.
- [ ] Test accepted and rejected image formats, file-size limits and multiple uploads.
- [ ] Confirm each successful application creates one row and private image objects.
- [ ] Confirm failed submissions do not show a success state.
- [ ] Configure owner notification and test delivery.
- [ ] Confirm the business email/contact route is monitored.

## Legal and privacy
- [ ] Confirm the retention schedule for unsuccessful applicants and reference images.
- [ ] Confirm privacy notice wording and data processor/subprocessor information.
- [ ] Confirm separate photography/video permission form and permitted channels.
- [ ] Confirm marketing opt-in remains optional and separate.
- [ ] Confirm cancellation and rescheduling terms are fair and solicitor-reviewed.

## Creative and content
- [ ] Select genuine portfolio photographs for the hero and launch posts.
- [ ] Confirm written permission for every image/video to be published.
- [ ] Produce campaign carousel artwork and Reel edit using actual work.
- [ ] Prepare story graphics and link sticker.
- [ ] Check captions, price accuracy and CTA links.
- [ ] Do not use concept descriptions or generated visuals as completed tattoo evidence.

## Measurement
- [x] Application and campaign tracking tables created.
- [x] Selection assessment table created with weighted score.
- [x] Booking, payment, session and content records created.
- [x] Dashboard and operational views created.
- [ ] Confirm dashboard totals against a controlled test record.
- [ ] Agree a weekly campaign review time and owner.
- [ ] Do not start paid acquisition until the response workflow is reliable.

## Release
- [ ] Review preview deployment.
- [ ] Approve the final copy, price presentation and legal wording.
- [ ] Remove temporary noindex directive only for the approved production release.
- [ ] Confirm canonical URL and search indexing.
- [ ] Deploy to production only after explicit approval.
- [ ] Publish the launch post and Stories.
- [ ] Review first enquiries and response times daily during launch week.
